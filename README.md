# Abdul Raheem — Developer Portfolio

A responsive, futuristic dark portfolio built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion. Your profile photo is included at `public/abdul-raheem.jpg`.

## Run locally

Requirements: Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Free deployment with Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel with GitHub and choose **Add New → Project**.
3. Import the repository. Vercel should detect Vite automatically.
4. Keep the build command `npm run build` and output directory `dist`.
5. Click **Deploy**. Vercel will provide a public `*.vercel.app` URL.

You must sign in and authorize GitHub/Vercel yourself. This assistant has prepared the source bundle but has not published it to a public hosting account.
